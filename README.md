# Vexo AI

Vexo AI — professional AI platform for building modern websites, Telegram bots, Android apps, web apps, APIs, and databases in one interface.

## Features

- AI chat workspace
- Project generation panel
- Dashboard for users and admins
- AI limit tracking
- Build and deploy monitoring
- GitHub integration hooks
- Admin user controls
- Dark premium design
- Mobile-friendly layout

## Stack

- Next.js 14
- TypeScript
- React
- CSS modules / custom CSS

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production deployment

This project is ready for Vercel deployment.

### Deploy to Vercel

1. Push this repository to GitHub.
2. Open https://vercel.com
3. Import the repository.
4. Keep the default Next.js settings.
5. Click Deploy.

## Environment variables

Create a `.env.local` file if needed:

```bash
NEXT_PUBLIC_APP_NAME=Vexo AI
NEXT_PUBLIC_API_BASE_URL=https://api.example.com
```

## Notes

This starter is a modern frontend demo and is structured to be extended with real backend logic later.
